# Pedra-Papel-e-Tesoura-Jogo-Interativo
🎮 Pedra, Papel e Tesoura
📌 Descrição do projeto

Este projeto é um jogo interativo de Pedra, Papel e Tesoura, desenvolvido como atividade prática para demonstrar os conhecimentos adquiridos durante o curso de desenvolvimento web.

O jogador escolhe entre Pedra, Papel ou Tesoura e compete contra o computador, que realiza uma escolha aleatória.

O jogo informa se o jogador venceu, perdeu ou empatou.

🚀 Tecnologias utilizadas
HTML5
CSS3
JavaScript
▶️ Como executar o projeto
Baixe ou clone este repositório.
Abra a pasta do projeto.
Localize o arquivo index.html.
Abra o arquivo em um navegador de internet.
Escolha entre Pedra, Papel ou Tesoura e divirta-se!
